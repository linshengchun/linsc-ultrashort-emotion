# LINSC超短情绪复盘系统

面向只做多、持股约2—3日的A股超短交易者。项目支持在网页选择交易日后手动生成或覆盖报告，并把结果保存为 Markdown、JSON 与 PDF 供阅读和归档。

## 工作方式

本地运行默认调用本机 Codex；线上版本使用可配置的大模型 API。客观指标始终由程序计算，大模型负责题材叙事、情绪周期与文字报告。

1. 网页选择交易日，点击“使用Codex生成本日报告”或“重新生成本日报告”。
2. 本地回环服务重新抓取该交易日数据并启动 `codex exec`。
3. Codex按固定Schema输出报告，程序完成结构校验、索引更新和紧凑版PDF渲染。
4. 同一交易日重新生成时直接覆盖本地旧报告。
5. 线上多模型API模式尚未启用，完成本地验收后再接入DeepSeek/OpenAI并发布。

报告文件位于：

- `data/reports/YYYY-MM-DD.md`：正式 Markdown 报告。
- `data/reports/YYYY-MM-DD.json`：网页摘要和关键指标。
- `public/reports/YYYY-MM-DD.pdf`：本地生成后上传的正式 PDF。
- `public/reports/index.json`：静态归档索引。

### 数据源分层

| 数据层 | 主来源 | 后备顺序 | 使用原则 |
| --- | --- | --- | --- |
| 客观行情层 | FTShare-MCP | AShareHub → 东方财富 | 用于价格、成交、涨跌分布、涨跌停、连板和昨日涨停反馈 |
| 题材归因层 | 同花顺问财 | 东方财富题材 → 公开市场资料 | 用于涨停原因、概念归类和题材事件树 |
| 市场叙事层 | 韭研公社 | 选股通 → 财联社 → 市场公开讨论 | 保留小作文和预期差，评价传播强度、想象空间与价格反馈，不做公告一致性核验 |
| 分析判断层 | LINSC规则引擎 | 最近5日静态报告 | 把客观数据、题材结构和核心反馈合成为周期、子状态、赚钱效应及接力难度 |

### 固定边界

- 股票范围排除名称含 `ST`、`*ST` 和北交所，纳入沪深主板、创业板与科创板。
- 报告不展示内部“数据完整性”模块；覆盖不足时在生成流程内部阻止或降级结论。
- 题材和个股消息按市场正在交易的叙事记录，不与公告做一致性核验，也不把小作文写成已经确认的事实。
- 不包含高标卡异动、绕异动模块。
- 不输出泛化的“次日操作”；只保留次日 1进2 的条件预判。

## 本地运行

```bash
npm install
npm run dev
```

构建和校验：

```bash
npm run build
```

启动本地网页与Codex生成服务：

```bash
npm run dev:local
```

默认网页地址由开发服务器输出，本地生成服务固定监听 `http://127.0.0.1:4317`，只接受来自 `localhost` 或 `127.0.0.1` 的网页请求。

也可以不经过网页，手动生成指定日期：

```bash
npm run data:fetch -- --date 2026-08-28
npm run report:generate -- --date 2026-08-28 --provider codex
npm run report:prepare
npm run report:pdf -- --date 2026-08-28 --output public/reports/2026-08-28.pdf
```

首次使用 PDF 渲染功能时安装依赖：

```bash
python -m pip install reportlab
```

## GitHub配置

本地Codex模式不需要在项目中配置大模型API密钥，但必须安装并登录Codex。可选环境变量：

- `CODEX_CLI`：Codex启动程序路径；Windows 默认使用 `codex.exe`，其他系统默认使用 `codex`。
- `CODEX_MODEL`：本地生成时使用的Codex模型；留空时沿用当前Codex配置。
- `CODEX_REASONING_EFFORT`：本地生成推理强度，默认 `high`；需要更深分析时可改为 `xhigh`。
- `LINSC_PYTHON`：PDF渲染使用的Python路径；Codex桌面环境会优先使用内置文档运行环境，否则使用 `python`。
- `LINSC_LOCAL_GENERATOR_PORT`：本地生成服务端口，默认 `4317`。
- `NEXT_PUBLIC_GENERATOR_URL`：网页调用的生成服务地址；开发模式默认 `http://127.0.0.1:4317`。

密钥、Codex登录信息和本地环境文件不会进入网页、报告或Git记录。

网页构建使用：

- `NEXT_PUBLIC_REPOSITORY_URL`：GitHub仓库地址。
- `NEXT_PUBLIC_REPORTS_RAW_BASE`：`public/reports` 对应的 raw.githubusercontent.com 地址。

密钥不会进入网页、报告或 Git 记录。
