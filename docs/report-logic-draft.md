# 《LINSC超短情绪复盘系统》报告逻辑底稿

> 状态：待确认底稿  
> 版本：V1.0-draft.9<br>
> 更新日期：2026-09-16<br>
> 本底稿用于继续完善报告逻辑，暂不替换现有正式生成器，不发布线上。
> 本次仅修订逻辑与验收标准，不生成、覆盖或上传日报；下列规则不代表现有程序已经实现。

本版重点修正四个容易让情绪判断失真的环节：核心池必须在D-1冻结，不能盘后看跌幅倒推角色；痛感增加“接近跌停但未封死”和“平开/高开后闷杀”；昨日板反馈同时看均值、中位数与左尾；1进2严格区分新启动首板、反包首板和二波首板，并把次日观察拆成竞价、开盘至10点、10点后决策三个时段。

## 一、系统目标

面向专业A股超短交易者，持股周期通常为2—3日、以做多获利。报告不是行情资讯汇总，也不是单纯列涨停股，而是每日的**赚钱/亏钱效应追踪、情绪连续性判断与次日交易决策底稿**。盘后回答五个核心问题：

1. 大盘环境与超短接力情绪是否一致？当前处于什么周期、什么子状态？
2. 活跃短线资金的持仓体感是舒服、分化还是高痛感？是否存在集中闷杀？
3. 次日接力的容错率与难度如何，风险是来自指数、题材还是高位核心杀伤？
4. 赚钱效应集中在哪里，亏钱效应是否已经扩散到情绪核心和昨日涨停样本？
5. 次日主攻什么方向和模式、观察哪些情绪锚、出现什么信号才参与、什么情况下放弃？其中哪些首板有1进2预期？

系统必须给出可执行的条件式操作应对，不能止于“情绪较差、谨慎参与”。条件式指导不等于无条件荐股：区分市场机会、触发条件和失效条件，不保证收益，也不替用户虚构持仓成本、风险承受能力或尚未明确的买入模式。

### 需求优先级

1. **最近几天谁在赚钱、谁在亏钱：** 先手与后手、首板与连板、主线与轮动、容量与小票分别看；尤其关注2—3日持有后利润是否保得住、亏损是否继续扩大。
2. **这种赚钱方式是否能延续：** 不是今天涨停就算有赚钱效应，要看昨日参与者今日的反馈、核心能否带动后排、分歧后能否恢复承接。
3. **今天相对前几天发生什么变化：** 修复、加速、分歧、退潮是否有数据支持，变化发生于全市场还是仅某个题材/风格。
4. **这些判断怎样影响明天：** 明确优先方向、可考虑模式、回避方向、确认锚点及强/平/弱三种情景的应对，而非只给一个周期标签。
5. **别的模型能否执行：** 本文件须同时定义来源、字段、公式、证据标准、判断路径、输出位置与缺失处理；不能依赖本对话的隐含知识。

### 分工原则

**数据负责回答发生了什么，分析负责解释短线资金的得失与变化，情景推演负责说明下一交易日怎样应对。** 每个关键判断都要有“证据 → 解释 → 反证/限制 → 操作含义”。确定性统计应能复算；主线认定、周期及操作情景属于有依据的判断，允许不同模型存在分歧，但不能改变输入事实或违反痛感否决。

## 二、股票范围与统计口径

- 排除名称中含 `ST`、`*ST` 的股票。
- 排除北交所股票。
- 纳入沪市主板、深市主板、创业板、科创板。
- 10cm与20cm分开统计、分开评价；20cm标的在报告中标为“20cm接力”或“弹性观察”，不与10cm连板使用同一标准。
- 同一份报告内的上涨家数、下跌家数、涨停跌停数、连板数、昨日涨停反馈必须采用同一股票范围。
- 历史数据缺失时写“—”，不得用当前热榜、当前题材或相邻交易日数据倒填。

### 日期、样本与价格约定

- `D`为复盘交易日；`D-1`、`D-2`等均指此前交易日，不是自然日。“次日”由交易日历确定，遇周末或节假日顺延。
- 每日股票范围按该交易日的上市状态、板块和名称确定；不得用今天的ST状态和成分名单无条件过滤历史。无法恢复历史范围时，记录口径限制，不伪称完全同口径。
- 每条行情校验其自身交易日与收盘状态，不能以整批数据最大时间戳或接口请求日期代替逐条校验。空值、异常缺失与经确认的零成交、平盘分别处理。
- 10cm、20cm按当日实际涨跌幅制度识别；无涨跌幅限制等特殊交易日不进入常规涨跌停、连板及1进2池，符合范围的有效成交仍计入成交额和涨跌家数。
- 涨跌停以当日实际涨跌停价及收盘状态判定；不得以“涨幅≥9.5%”“跌幅≤-9.5%”统一代替，更不能将20cm大跌误判为跌停。价格比较使用一致价格基准和最小报价单位，除权除息日使用有效参考价。
- 客观统计由原始数据确定性计算，先计算后四舍五入；模型负责解释，不自行补数、改数或估计统计结果。

## 三、周期判断框架

### 1. 主周期

- **混沌期：** 缺少大消息与大政策，各类小题材冒头1—3日，覆盖面小、资金介入浅；成交量持续萎缩，活跃资金以小仓位试错为主。
- **主升期：** 政策与消息密集，活跃资金仓位提升；主流题材持续主升，连板梯度完整，题材内部出现高低切或向分支题材扩散。
- **电风扇期：** 多个题材并存但缺少绝对主线，多数题材处于高位震荡；市场成交额维持高位，量化与轮动资金主导，追高持续性弱。
- **主跌期：** 政策打压或核心逻辑被证伪，高标出现A杀，关键K线破位；活跃资金明显减少或以净卖出为主，亏钱效应连续扩散。

### 2. 当日子状态

根据当日盘面标记冰点、修复、加速、分歧、强分歧、主线切换或退潮。子状态必须结合题材所处阶段判断，不能只看指数涨跌或涨停家数。正式结论必须同时写出“大盘环境状态”和“超短接力状态”，禁止用“指数上涨、涨停增加”直接覆盖高标跌停和接力闷杀。

### 3. 大盘环境与超短接力双轴

周期判断先分成两条轴：

- **大盘环境轴：** 成交额、指数、上涨/下跌家数、涨停/跌停宽度和市场流动性。
- **超短接力轴：** 昨日涨停反馈、高标晋级、前期情绪核心负反馈、早盘跌停、大面扩散和题材前排承接。

两条轴不一致时，以超短接力轴决定短线可做性，并在结论中明确背离：

| 大盘环境 | 超短接力 | 结论方向 |
| --- | --- | --- |
| 强 | 强 | 主升延续或主升加强 |
| 强 | 弱 | 指数修复、短线退潮／高痛感高低切 |
| 弱 | 强 | 局部题材抱团，非全面转强 |
| 弱 | 弱 | 主跌或退潮扩散 |

“指数修复、短线退潮”不是矛盾表述，而是超短复盘必须保留的结构性结论。

### 4. 超短情绪痛感

痛感单独评价活跃短线资金的实际盈亏和被套体验，不与市场上涨家数简单平均。痛感来源包括：

- 前5个交易日涨停股、3板以上个股、题材锚点和高辨识度核心的早盘跌停；
- 前期情绪核心从涨停或高位快速跌停、大跌、A杀；
- 昨日涨停样本次日红开率、平均开盘和大面率同步恶化；
- 跌停从后排扩散到主线前排、容量中军或多个题材核心；
- 早盘9:25—10:00集中跌停造成竞价和开盘后的风险厌恶。

#### 观察池、核心池与时间线

- **观察池：** D前5个交易日曾收盘涨停的个股，加上此前已确认的高标、题材锚与容量中军，按代码去重。不能只从D的收盘跌停名单倒找样本。
- **核心池冻结：** 每个交易日D必须读取D-1收盘后已生成的`core_snapshot_D-1`。核心角色只允许依据D-1及以前的信息确定，禁止因D暴跌才事后加封“龙头”；D当日新出现的核心只能进入下一交易日快照，不能反写D的痛感统计。
- **A/B/C三级角色：** A级为市场高度锚、已确认主线最高标或连续3板及以上的高辨识度核心；B级为有D-1证据的主线前排、容量中军、换手核心或20cm弹性锚；C级为普通昨日涨停、题材候选或当日新辨识度个股，只进观察池，不计入“高位核心”阈值。多重角色保留全部标签，但统计权重只取最高级。
- **快照字段：** 至少保存代码、名称、角色日期、角色级别、主归属题材、全部角色标签、入池依据、最近一次满足依据的交易日、有效截止日、状态和证据路径。缺少快照或关键依据时，核心指标写“—”或已确认下限，不能盘后凭印象补成精确值。
- **生命周期：** A/B级角色自最近一次满足依据起默认保留5个交易日；期间若继续晋级、保持题材前排或容量地位则顺延，失去依据后到期退出。停牌期间角色保留但不进入缺少有效行情的当日价格分母；退出后的历史记录不删除。规则只决定观察资格，不等于5日内都具有同等强度。
- 观察池与核心池分别保留原始明细；模块二的“高位核心早盘跌停”“核心收盘大面”使用核心池，模块三的大面使用昨日涨停样本，两者不能互相代填。
- **早盘跌停数：** 核心池中09:25—10:00至少一次进入实际跌停的股票数，每只只计一次；收盘打开的仍保留。只有盘中触价但没有时间证据，不能计作已确认的早盘跌停。
- **早盘重伤数：** A/B级核心在09:25—10:00任一有效采样点涨跌幅≤-7%的数量，早盘跌停也计入；必须有竞价或分钟级时点证据，日线最低价不能替代。另存其中A级、B级数量，防止普通活跃票数量稀释关键锚杀伤。
- **收盘跌停数、收盘大面数：** 核心池中分别满足收盘跌停、收盘涨跌幅≤-5%的数量；同一只可以同时进入两项，但不合并相加。
- **日内闷杀数：** 有有效开盘价的A/B级核心中，`收盘价/开盘价-1≤-5%`的数量；其中开盘涨幅>0且收盘涨跌幅≤-5%的，另记“红开闷杀”。该项识别平开或高开后被兑现，不能用收盘涨跌幅单独替代。
- **核心跌停占比：** 核心池收盘跌停数 / LINSC范围收盘跌停总数；分母为0时写“—（当日无收盘跌停）”，不能用早盘触跌停数作分子。
- 每只负反馈股串联“前日角色 → 竞价/开盘 → 早盘触板及打开 → 午后变化 → 收盘 → 对同题材和接力的影响”。日K线的高、低价不能证明高低点发生时间，也不能证明有资金全天被封死。

#### 核心杀伤分

内部保留原角色权重，并明确计分事件：核心池中**收盘跌停**的市场高度锚或主线最高标计3分，主线前排、3板以上或容量核心计2分，昨日涨停或高辨识度情绪票计1.5分，其他已入池活跃票计1分。多重角色只取最高一档，不重复累计。

核心池中09:25—10:00触及跌停每只另加0.5分，即使收盘打开也保留；同一主归属题材至少2只核心收盘跌停，该题材额外加1分，每个题材只加一次，多概念个股不得跨题材重复贡献加分。此项是共同收盘负反馈加分，不等于证明它们在同一分钟下跌。角色分、早盘分、题材分分别保存。

该分数是待校准的辅助规则，不是经回测验证的预测指标。早盘闷杀后打开可能只贡献早盘分，但仍触发下述痛感否决，不能因总分低就忽略。历史核心池或时点数据不完整时写“—”，不把部分得分当完整得分进行近5日排名。

痛感等级先计算以下硬信号：

- `A1`：至少3只A/B级核心在09:25—10:00实际触及跌停。
- `A2`：至少4只A/B级核心在09:25—10:00涨跌幅≤-7%，且至少2只是A级核心；A2用于识别尚未封死但已经造成强烈风险厌恶的集中重伤。
- `B`：至少2只A/B级核心收盘跌停。
- `C`：昨日涨停红开率<40%，或平均开盘涨幅<-1%。
- `D`：昨日涨停样本收盘大面率≥15%，且中位收盘涨幅<0或样本平均开盘至收盘收益≤-2%。
- `E`：至少2只A/B级核心收盘大面，或至少1只A级核心发生红开闷杀。

据此判定：

- **低痛感：** 核心股多数正常，亏损主要在后排，接力反馈稳定。
- **中痛感：** 高位出现明显分歧，红开率下降，个别核心大跌。
- **高痛感：** `A1 或 A2 或 (B 且 C) 或 (D 且 E)`。均值为正也不能抵消A1/A2，少数连板股抬高均值时必须服从左尾和核心杀伤。
- **极高痛感：** 已达到高痛感，且下列附加条件至少同时满足两项：多个题材的A级核心收盘跌停；市场或主线高度明显下降且无同级新锚承接；昨日涨停大面率≥25%；昨日涨停跌停扩散到不同题材。只写“集中闷杀”必须能列出对应个股和题材。

若市场高度锚或主线最高标单独收盘跌停，且没有同等辨识度的新核心承接，至少判为中痛感；若该标的早盘即跌停，或同时伴随昨日涨停反馈恶化，至少判为高痛感。这样可以避免“跌停数量不多，但最关键的锚点被杀”被平均数稀释。

痛感达到高或极高时，最终结论不得写成“主升延续”或普通“弱修复”；只能写成“指数修复、短线退潮”“高位杀跌、低位抢跑”或相应更谨慎的状态。

### 5. 情绪温度

满分100分，仅用于辅助比较，不直接替代周期状态机，也不能抵消高痛感否决条件：

| 维度 | 权重 | 主要指标 |
| --- | ---: | --- |
| 市场、量能与涨跌分布 | 15 | 成交额变化、上涨/下跌家数、涨停/跌停数 |
| 昨日涨停次日反馈 | 20 | 红开率、平均开盘、收红率、平均收盘、晋级率、大面率 |
| 高位核心杀伤与情绪痛感 | 25 | 早盘核心跌停、高位跌停、A杀、大面扩散、核心杀伤率 |
| 连板梯队与高标 | 20 | 最高板、连板家数、梯队完整度、高标晋级和断板方式 |
| 题材持续性与风格 | 20 | 主线强度、核心承接、容量、20cm、低价、反包和追高反馈 |

周期结论由双轴规则、痛感否决和状态迁移得出，不能仅按温度分数机械划段。报告在第二模块提前展示周期结论，但系统应先完成第三至第八模块的计算，再回填该结论。

在五项子分的映射方法、缺失处理和历史校准尚未固定前，不输出貌似精确的“25/100”等温度值，写“温度未量化”即可；不能由模型凭语感配分。主周期只使用前述四类，“退潮”属于子状态，不另设“退潮期”作为第五类。量化资金或游资主导、仓位重等若没有对应证据，只能作为可能解释，不能当作已观察到的事实。

### 6. 连续性与状态迁移

- 前几日报告提供“当时判断、关键锚、预期与证伪条件”，不提供免复核的数字真值。当日必须检验此前条件是兑现、落空还是仍待观察，并允许推翻前日报告。
- 区分“指数改善”“题材局部修复”“整体接力修复”。单只高标晋级、跌停数减少或低位首板增加，均不能独立确认整体修复。
- 接力修复需要核心杀伤缓解、昨日涨停反馈改善、题材前排承接与可参与晋级共同支持；第一次出现写“修复尝试”，后续持续才上调。修复失败则明确哪项条件失效，不把日内冲高回落笼统写成弱修复。
- 主升确认需持续性、梯队和参与面共同支持；缺乏绝对主线但轮动活跃可判电风扇，不能仅凭多题材并存就忽视核心连续杀跌而归入电风扇。

## 四、正式报告九个模块

### 模块一：当日结论

用以下5条高度压缩的结论概括，按顺序输出：

1. **大盘环境：** 指数、量能、宽度和流动性属于什么状态。
2. **超短接力状态：** 高标、前期核心、昨日涨停样本和早盘负反馈属于什么状态。
3. **情绪痛感：** 低痛感、中痛感、高痛感或极高痛感，并列出造成痛感的主要个股群和扩散路径。
4. **接力可做性：** 容错率、风险来源、赚钱效应是否足以覆盖旧核心亏损。
5. **主线与切换：** 主线、分支、低位抢跑或退潮方向，以及周期与子状态。

结论必须明确允许“大盘环境偏强、超短接力偏弱”的背离，不得用指数上涨或涨停家数回升将超短情绪直接判定为修复。不得重复罗列后文数据。

### 模块二：大盘基础行情、近5日与周期定位

包含：

- 当日成交额，以及相对前一交易日和近60日平均成交额的增减额、增减百分比。
- 上涨家数、下跌家数、涨停家数、跌停家数。
- 连板家数、最高板。
- 主要指数表现以及“指数与短线情绪是否背离”。
- 最近5个交易日的成交额、涨跌家数、涨跌停数、连板数、最高板、核心杀伤、情绪痛感、当日子状态对比表。
- **双轴结论：** 分别写出大盘环境轴和超短接力轴，再给出二者是否背离。
- **高位核心杀伤：** 统计前5个交易日涨停股、3板以上个股、题材锚点及高辨识度核心的早盘跌停数、收盘跌停数、收盘跌幅≤-5%数、核心杀伤分，以及这些个股在全市场跌停中的占比。
- **痛感与接力判定：** 写出痛感等级、主要受伤资金群、接力容错率和风险来源。
- 主周期、当日子状态、情绪温度及成立依据。
- 下一阶段的状态转移条件：哪些信号确认继续主升、转电风扇或进入退潮。

#### 当日成交额比较规则

成交额必须采用同一LINSC股票范围计算，不能把不同统计口径的官方两市总成交额、网页统计值和过滤后个股成交额混用。设当日成交额为 `T0`、前一交易日成交额为 `T1`，当日前最近60个完整交易日的平均成交额为 `MA60`，则：

- 较前一交易日增减额：`T0 - T1`。
- 较前一交易日增减百分比：`(T0 / T1 - 1) × 100%`。
- 较近60日均值增减额：`T0 - MA60`。
- 较近60日均值增减百分比：`(T0 / MA60 - 1) × 100%`。
- `MA60`不包含当日，等于此前60个完整交易日各自LINSC成交额总和除以60，不是股票均值。经确认的停牌零成交可以计0；缺失行情不能计0，也不能直接略过缺失日后缩小分母。
- 个股成交额统一转换为元后求和，再换算亿元；“万元、亿元、元”和涨跌幅的“小数比例、百分数”必须在字段层明示，不能凭数值大小猜单位。
- 未过滤的沪深成交额可作为另行注明的背景信息，但不得进入本表或替代T0、T1、MA60；日间范围变化由当日成分决定，不用固定的今天股票池回算历史。

正文固定写明：当日成交额、前一交易日成交额、较前一交易日增加或减少的亿元数及百分比、近60日平均成交额、较60日均值增加或减少的亿元数及百分比，并据此判断量能所处位置：

- 当日高于前一交易日且高于60日均值：流动性扩张，支持主升或强修复，但仍需接力轴确认。
- 当日低于前一交易日但高于60日均值：高位缩量，倾向分歧或存量轮动，不能直接判为流动性枯竭。
- 当日高于前一交易日但低于60日均值：低位放量修复，属于边际改善，不能仅凭放量确认主升。
- 当日低于前一交易日且低于60日均值：流动性收缩，偏弱、退潮或混沌缩量环境的概率上升。

近60日均值及其偏离只在本模块的当日成交额说明和量能判断中展示，不在近5日对比表中增加独立列；近5日表继续沿用“成交额/环比”字段。

近5日对比表至少采用以下字段，避免只看指数和涨停数量：

| 日期 | 成交额/环比 | 上涨/下跌 | 涨停/跌停 | 连板数 | 最高板 | 高位核心早盘跌停 | 核心收盘大面 | 杀伤分 | 情绪痛感 | 大盘环境 | 超短接力 |
| --- | --- | --- | --- | ---: | ---: | ---: | ---: | ---: | --- | --- | --- |

表格行按交易日期倒序排列：最新交易日在第一行，最早交易日在最后一行；不得按正序输出。

二模块的周期结论以超短接力轴为主裁决轴。若指数、成交额和涨停宽度改善，但高标杀伤或昨日涨停反馈恶化，必须写成“指数修复、短线退潮”或“高位杀跌、低位抢跑”等结构性结论，不能归入普通弱修复。

本模块是**总览与裁决**：近5日表、痛感等级、核心杀伤摘要，以及“前日判断 → 今日验证 → 状态是否迁移”。完整个股杀伤时间线仅在模块五列一次，昨日涨停完整反馈仅在模块三列一次；不另建重复的连续性模块。

### 模块三：昨日涨停股次日反馈与近5日对比

只保留一个最近5个交易日综合表；接力反馈与痛感指标放在同一张表，不另起一张重复表：

| 日期 | 样本 | 红开数/率 | 平均开盘 | 收红数/率 | 平均/中位收盘 | 开盘→收盘 | 晋级数/率 | 大面数/率 | 跌停数 | 接力痛感 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |

表格行按交易日期倒序排列：最新交易日在第一行，最早交易日在最后一行；不得按正序输出。

规则：

- 每行日期为反馈发生日D，样本来自D-1收盘涨停池，不能把D盘中触板或炸板股混入昨日池。
- 表内样本使用具备D有效参考价、开盘价、收盘价及收盘涨跌停状态的昨日涨停股，所有比例统一分母N。内部另存原始样本N0和排除原因；N不足N0时表中写“N/N0”，表下注明为有效子样本，不能暗示全样本结论。
- 红开成功率 = 开盘价高于D有效参考价的数量 / N；平开不算红开。收红率、晋级率、大面率同用N；停牌、行情缺失不按平盘或失败处理。
- 平均开盘、平均/中位收盘分别为各有效样本相对D参考价的涨跌幅，不按市值加权；中位数为强制字段，不能只报均值。`开盘→收盘`为每只股票先计算`收盘价/开盘价-1`后再取均值，不能用“平均收盘涨幅－平均开盘涨幅”替代。
- 后台必须同时计算收盘涨跌幅P25、最差10%样本均值、≤-7%数量及≤-9%/实际跌停数量，用于观察左尾；样本过少无法稳定计算最差10%时，直接列最差个股及跌幅，不强算分位数。
- 若平均收盘为正，但中位收盘为负或大面率≥15%，结论必须写“收益集中、普通样本亏损”，不得写成整体接力修复；若红开率尚可但`开盘→收盘`显著为负，应写“竞价有承接、盘中兑现”。
- 后台分别计算10cm和20cm反馈；正文可展示综合表，但出现明显背离时必须在表后说明。
- 对比红开率与收红率、平均开盘与平均收盘，识别“竞价强、盘中兑现”或“低开修复”等结构。
- **收盘大面数/率**定义为昨日涨停样本中次日收盘跌幅≤-5%的数量及其占比；**跌停数**为其中次日收盘跌停数量。两项用于识别接力亏损是否从低开扩散为集中闷杀。
- 表后必须说明痛感来自哪些角色：高标、主线前排、容量中军、昨日涨停样本，还是仅后排个股；不能只给综合平均数。
- 后台同时保留昨日首板、昨日2板及以上的分组反馈，以及D-2、D-3涨停批次在D的表现，解释2—3日持仓是否持续受伤；正文有显著差异才用短段说明，不增加第二张5日表。20cm组样本很少时写明数量，不能用单只晋级推广成整体改善。

### 模块四：连板梯队与接力结构

- 分别列出10cm和20cm连板梯队。
- 分析梯队是否完整、断层位置、同身位竞争、换手与一字结构。
- 关注连板晋级率、炸板率、高位断板反馈，以及首板是否能持续补充梯队。
- 20cm不得直接折算成10cm板数，只作为独立弹性与风险偏好信号。
- 连板指连续交易日收盘涨停；“5天3板”等非连续口径只写作阶段强度，不当成3连板。首板为D收盘涨停且D-1未收盘涨停；新股、停复牌跨期等特殊情形单独标注，不硬接连续梯队。
- 必须区分“盘中触板数”“盘中曾开板但收盘回封数”和“收盘未封住的炸板数”。本报告炸板率 = D触及涨停但未收盘涨停的去重股票数 / D全部触及涨停的去重股票数，不能把所有曾开板记录都当成最终炸板。
- 不同高度分组的晋级分母为昨日对应板数的有效样本；一字板与可换手参与的晋级分开解释。没有20cm连板时明确写0，不凭空列弹性梯队。

### 模块五：高标、情绪锚与题材影响

至少识别以下角色：

- 市场高度锚。
- 主线高度锚。
- 换手核心。
- 容量中军。
- 20cm弹性锚。
- 负反馈锚。

逐只说明其情绪地位、当日表现，以及对板块扩散、同身位竞争和全市场接力风险偏好的影响。高标不能只按板数排序，必须区分独立抱团、题材龙头和容量核心。

#### 情绪杀伤清单

当日出现明显负反馈时，单独列出最影响短线资金体感的个股群，而不是把它们埋在涨跌停统计中。每只至少记录：

- 股票及前一日角色（高标、昨日涨停、主线前排、容量中军、辨识度核心等）。
- 竞价表现、9:25—10:00早盘表现、最终收盘表现。
- 是否跌停、是否从高位快速下杀、是否形成A杀或大面。
- 对同题材、同身位和次日接力的影响。

当多只情绪核心在早盘同步跌停时，要明确写出“集中杀伤”及其对活跃短线资金的风险厌恶影响。类似8月31日早盘集中跌停的情绪票群，不能仅作为个股涨跌记录，必须作为情绪负反馈样本解释；具体名单以当日角色识别结果为准，不在底稿中固化。

同时区分“封死导致退出困难”“反复打开但承接弱”“高开后大幅兑现”“断板后连续下跌”，不能都写成全天闷杀。涨跌停记录可以证明触板与开板，不能证明投资者实际成交或所有持仓都无法卖出。角色可以一股兼任，但统计去重；缺乏清晰容量中军或20cm锚时直接说明尚未形成，不为凑齐角色指定个股。

### 模块六：涨停题材事件树与结构分析

将原“涨停原因与题材事件树”和“题材结构：消息、逻辑、预期与想象空间”合并，但采用“事件优先、题材归纳其次”的写法。不能先把所有内容压缩成泛化题材，再反推个股原因。每个重点题材统一包含：

1. **题材阶段：** 试错、发酵、主升、加速、分歧、回流或退潮。
2. **事件清单：** 先逐条列出当日真正被交易的具体事件或消息，例如订单、中标、涨价、产品发布、政策预期、并购重组、极端天气、海外事件或市场小作文；每条事件保留触发时间、涉及个股、原始叙事要点和当日价格反应。
3. **个股映射：** 说明事件为什么映射到该公司，区分直接受益、产业链间接受益、概念标签和纯情绪跟风，不能只写“属于某某题材”。
4. **消息面：** 同花顺问财的涨停原因和事件映射，并补充韭研公社正在传播的个股异动、板块资讯、小作文与市场讨论；不在正文标注“韭研来源”。
5. **扩散路径：** 从单一事件向产业链、地域、属性或分支题材如何扩散，记录先涨个股、跟随个股和扩散时间顺序。
6. **涨停映射：** 核心、补涨、容量、20cm弹性及后排代表，并标明各自对应的具体事件。
7. **逻辑面：** 资金为何愿意交易该事件，逻辑是否能形成板块合力，容量是否足够，事件是一次性刺激还是可以连续发酵。
8. **预期与想象空间：** 市场当前在定价什么、仍有哪些预期差、后续升级条件和证伪条件；不得用宽泛题材想象替代具体事件依据。
9. **持续情况：** 已持续多少交易日，事件是否重复传播、是否出现新催化，梯队、宽度、强度和次日反馈如何变化。

同一题材下的不同事件不能强行合并；同一事件被多篇帖子重复传播时，合并为一个事件主体，但保留首次出现时间、后续传播时间和不同个股映射。题材总结是上层索引，不能覆盖事件清单和个股映射。

主线不能只看当日涨停数量。按五项门槛判断：持续性、板块高度、低位扩散宽度、容量承接、次日正反馈。**已确认主线**必须同时具备持续性和次日正反馈，并在其余三项中至少满足两项；首日爆发只能写“主线候选”，即使涨停很多也不能当日直接确认。只有消息和宽度、没有连续反馈的，写“一日轮动”；已有确认主线若在高度、容量和次日反馈上不再明显领先，降为“多题材活跃/电风扇”，不能继续沿用旧主线称号。

#### 消息展开与时点边界

- 不按固定3个题材、每题材2条消息或每股一个事件截断内容。覆盖当日主要赚钱题材、旧主线负反馈、最高标所在题材及候选所属题材；有效消息少就如实少写，不为条数填充背景常识。
- 每条关键消息写出“谁、发生/传播了什么、时间、涉及产品或业务、如何映射到个股、市场为何在此时重新交易”。对老消息明确是旧催化延续还是新增催化，不把旧帖子重新抓取时间写成新消息发布时间。
- 区分已披露事件、市场传闻、帖子推演和本报告推断；不要求公告核对，但要有实际内容依据。“有帖子”不等于“已广泛传播”，多个独立传播节点才支持扩散判断。
- 每条关键事件标记“当日新增、此前延续、旧闻再传播、盘后后续催化”之一。盘后才出现的内容只能进入次日预期，不能用于解释D盘中的封板；旧闻再传播必须说明本次重新交易的新增条件，不能把发布日期或采集时间混成事件发生时间。
- 各事件记录事件时间、可确认的首次传播时间、帖子发布时间、采集时间四类时点；不确定的不得互相替代。历史报告默认以D收盘为盘面归因截止，D盘后消息如使用须单列为后续催化，不能解释D盘中上涨；D之后消息不回填。
- 同花顺的题材标签只负责归类，韭研正文负责展开事件。早封只能说明时间领先，不能单凭先后就断言“该股带动其他股票”或“资金从A流向B”；因果链不充分时写同题材联动或推断。
- 原文缓存可用时从缓存提取事件卡；网页可访问但只有首页、导航或空正文不算采集完成。没有有效事件映射的股票可以保留客观表现，不虚构炒作原因。

### 模块七：近期题材持续情况

- 按重点题材展示最近若干交易日的阶段变化。
- 每个交易日必须列出“发酵表现”和“当日领涨核心票”。
- 观察首日试错、次日确认、梯队扩展、分歧、回流与退潮的连续过程。
- 历史结论只能来自对应交易日的静态数据或报告；缺失写“—”，不得用今天的热门概念回放过去。
- 默认覆盖与模块二、三相同的5个交易日；每个重点题材按日写“阶段/新增催化 + 当日领涨核心及板数或涨跌幅 + 原核心是否接续”。不能五天都机械重复今天的龙头。
- 区分连续活跃、断续回流和仅单股抱团；“持续5日”须5日都有可回放的依据，休眠后回流不能算连续主升。前期题材或核心失效也要保留其退出过程，避免只写幸存者。
- 模块六解释今天的事件机制，本模块只解释沿时间发生的延续、掉队与换锚，不重复铺陈整段消息。

### 模块八：赚钱效应、亏钱效应与接力难度

对下列风格分别评价：

- 10cm连板接力。
- 20cm弹性。
- 容量趋势。
- 低价小票。
- 二波。
- 反包。
- 复牌股。

明确赚钱效应集中在哪里、亏钱效应集中在哪里，并把接力难度分为：容易、中等、中等偏难、困难、极难。判断要结合竞价溢价、盘中兑现、晋级率、炸板率、高位负反馈和题材集中度。

每种风格至少给出样本个股、当日表现与隔日/2—3日反馈依据，区分“账面涨幅”与“普通接力资金能否参与”。只见首板涨停、全天一字或后排普亏，不算可复制的赚钱效应；没有有效样本时写“暂无有效样本”，不能省略风格或凭印象判断。低价、容量、二波、反包的归组依据在内部保留，避免随盘面结论临时换组。

#### 超短资金体感与闷杀扩散

- 额外给出“舒服、一般、分化、差、高痛感”五档体感；体感由高位核心、昨日涨停样本和早盘负反馈优先决定。
- 赚钱效应若只集中在低位新题材、首板或少数20cm，而旧主线高标和昨日涨停样本普遍亏损，必须写明“局部有赚钱效应，但活跃接力资金体感差”，不能用赚钱效应存在替代情绪修复。
- **闷杀风险**重点观察：竞价或开盘曾有承接、随后收盘跌幅≤-5%；前一日涨停次日跌停；高标断板后继续大跌；同一题材前排与后排同时转弱。满足多项时，接力难度至少评为“困难”。
- 记录亏损是否从单一个股扩散到主线前排、容量中军、多个题材核心和昨日涨停样本；扩散越广，次日接力越应按退潮风险处理。

#### 双轴复盘校准示例

当指数上涨、成交额回升、涨停数增加，但早盘多只情绪核心跌停，高标高度下降，昨日涨停红开率和平均开盘显著恶化时，统一表述为：**大盘环境修复，超短接力退潮，情绪痛感高；低位新题材可能抢跑，但不足以覆盖旧核心杀伤。**

这类盘面不能归类为“普通弱修复”，也不能因为低位出现首板就判定主升重新启动。只有当高位杀伤停止、昨日涨停反馈连续改善、主线前排重新获得承接并出现可复制的晋级梯队，才允许将接力轴上调为修复或主升延续。

### 模块九：次日情景推演、操作应对与1进2预期标的

本模块承接前八模块，先给整体操作应对，再给1进2候选。根据2026-09-06最新需求，替代此前“只列候选、不写次日操作”的限制；仍保留九模块结构，不另加重复的第十模块。

#### A. 次日交易重心

- **基准判断：** 当前最有证据支持的是进攻、局部参与还是防守观察，理由来自哪一段赚钱/亏钱效应，而非固定温度分数。
- **优先方向与模式：** 列重点题材、核心/补涨/容量等位置及可考虑的模式，解释其相对优势与后手风险；没有明确主攻方向时直说，不能为凑计划强选一个主线。
- **回避方向与模式：** 点明哪些旧核心、同身位后排或兑现风格仍在持续伤害接力资金，什么信号出现前不恢复优先级。
- **观察锚：** 具体到股票或昨日涨停样本，写出竞价、09:25—10:00及后续时段应观察的承接变化；盘口确认只能留给次日，盘后不能预填。
- **已有持仓与新开仓分开：** 前者评估题材/核心是否仍支持延续，后者评估后手是否还有空间与可参与性。未提供实际持仓和成本时，只写对应类别的处理条件，不冒充个性化持仓指令；仓位百分比和精确执行价待用户操作模式明确后再细化。

#### B. 次日三段观察与接力许可

盘后报告不预判次日盘口结果，只把次日决策拆成三个时间段，并给出需要复核的对象：

1. **09:25竞价风险扫描：** 先看D日冻结的A级高度锚、主线核心、负反馈锚和D日涨停样本整体开盘分布，再看候选自身。若关键锚继续被按跌停、昨日板批量低开或高位无承接，先下调环境许可，不能因单只候选高开就忽略系统风险。
2. **09:30—10:00确认：** 统计A/B级核心实际触跌停和≤-7%重伤，观察主线前排、容量中军、后排及同身位竞争是共同承接还是快速分化；同时复核候选是否具备换手承接、题材扩散和可参与性。只有日K数据时不得伪造这一阶段结论。
3. **10:00后形成许可：** 根据已发生信号给出`进攻许可`、`局部许可`或`无新增接力许可`。进攻许可要求核心杀伤收敛、昨日板反馈改善且至少一个已确认方向形成可复制承接；局部许可表示只允许已验证题材/模式的前排观察；无新增接力许可表示硬风险仍在，不再用单股故事覆盖环境。许可是风险门槛，不是自动买入指令。

日报需把每段对应的具体股票、题材和批次写清；次日报告再复核实际触发过程，禁止盘后把未发生的盘口条件写成事实。

#### C. 情景与应对表

| 次日情景 | 必须观察的确认信号 | 对应应对 | 失效/切换条件 |
| --- | --- | --- | --- |
| 强于基准 | 具体核心负反馈缓解、前排承接和昨日板反馈共同改善；逐日报告填实际锚点 | 提升已验证题材/模式的观察优先级；说明参与仍需哪项个股确认 | 核心修复失败、跟随股不承接或高开兑现，则退回基准/弱情景 |
| 符合基准 | 主要锚点及题材结构按盘后判断延续 | 只执行基准方向及条件，不把轮动普遍化为进攻机会 | 主线竞争格局或赚钱效应改变，重新排序 |
| 弱于基准 | 核心继续被按跌停、昨日板反馈恶化或预期题材低于预期 | 降低新增接力意愿，取消失效候选，优先审视同类持仓风险 | 只有真实承接恢复且负反馈收敛，才重评修复，不因单股拉升改变结论 |

上表是写作结构，日报必须替换为当日具体股票、题材、确认信号与应对，不得原样复制成空泛的“高开就强、低开就弱”。三种情景不编造发生概率。复盘次日时检验实际触发了哪种情景、原条件哪里有效或失效，形成闭环。

#### D. 1进2候选

从当日全部合格首板中筛选，先按形成方式分组：`新启动首板`、`反包首板`、`二波/N日M板首板`。常规“1进2预期”只在新启动首板中排序；反包和二波标的放入单独观察组，不得凭当日重新涨停混入普通首板排名。10cm和20cm继续分开评价。参考维度包括：首次涨停时间、开板次数、回封质量、封板强度、成交与换手、题材地位、同题材竞争、历史股性、韭研公社炒作叙事和当日定价程度。

每只候选统一包含，且炒作逻辑必须保留事件细节：

- **异动解析：** 优先使用韭研公社个股异动解析，第一段必须写清具体事件、事件发生或传播时间、公司与事件的对应关系、当日直接触发和资金正在交易的核心信息；不得只写题材名称或概念标签。
- **帖子吹票逻辑：** 第二段结合板块文章和其他帖子，写清同一事件如何传播、是否出现新的催化、资金从哪只个股向哪些分支扩散、预期差、想象空间以及当前是否已经充分定价。
- **接力预判：** 单独写成立条件、竞争关系、风险点和证伪条件。

补充规则：

- 找不到个股异动解析时，不标注“未取得”，直接使用有效的板块文章和帖子补写。
- 若完全没有有效的韭研公社个股或板块叙事证据，则不纳入候选。
- 事件内容不足以说明个股映射时，不得用题材名称、封板时间或历史股性补猜具体消息。
- 正文不展示帖子标题、作者、链接和发布时间。
- 名称梗、谐音梗只能增加辨识度，不能单独支撑A档。
- 20cm首板标为“20cm接力”或“弹性观察”，不与10cm首板争夺同一晋级名次。
- 候选预期服从本模块整体情景，不以单股故事推翻市场接力风险；候选不等于买入指令，必须保留成立、参与确认和放弃条件。
- 当日情绪达到高/极高痛感时不评A档；次日进入“无新增接力许可”时，全部普通1进2候选自动取消，只保留为盘后复盘样本。局部许可下只能保留与已验证方向一致且满足个股确认的观察标的。

#### 候选筛选与证据要求

- 先扫描全部合格首板，内部记录入选或排除原因，再形成候选；不先选熟悉的股票后找理由，也不规定必须凑满3只。允许0只，说明当天不具备可支持的候选条件。
- 扫描结果必须记录首板类型、前5个交易日涨停经历、是否反包/二波、10cm/20cm、候选组和排除原因；“首板”仅描述D日连板状态，不自动等同于新启动。
- 每只候选先给客观依据：10cm/20cm、首次封板、最终回封、开板次数、成交额、换手率及可取得的封单指标。封单需写明时点、单位和分母；没有封单数据不能以“早封、少开板”替代称为资金封单强。
- 股性必须有可回放的历史样本，如前期首板后反馈、连续晋级或冲高回落记录及样本日期；“老妖、股性活”不是证据。没有相关历史数据就不靠该项加分。
- 两段炒作逻辑分别承担“具体触发与个股映射”和“其他帖子如何扩展故事、预期差及分歧”，不能把同一概念换词重复。不存在新增传播证据时不虚构吹票热度。
- 接力预判按“题材需如何延续、核心锚需如何表现、同身位谁更强、个股承接需满足什么、出现什么即失效”写条件链。没有分时或盘口证据时不编精确竞价涨幅、成交量阈值和涨停概率。
- 环境高痛感时，候选只能表示相对观察优先级，不等于接力环境转好；正文要区分先手收益、后手承接风险和可参与性，不输出无依据的A档或确定性晋级承诺。

| 一、当日结论 | 其余模块的已验证结果 | 综合双轴、痛感和连续性，不新增数字 | 最近几天赚钱效应如何变化、当前交易重心是什么 | 先明确交易姿态及主要风险 |
| 二、大盘与周期 | D1、D2、D5、核心杀伤结果、D8 | 同范围量能比较、五日变化、前日条件验证、双轴裁决 | 流动性支持度、周期/子状态、指数与接力是否背离 | 确定整体进攻或防守的背景，不直接生成买点 |
| 三、昨日涨停反馈 | D1—D3 | 前日池与当日行情交叉计算；分10/20cm、首板/连板 | 先手能否兑现、后手是否被兑现，改善是否可持续 | 判断接力容错率及高低位取舍 |
| 四、连板梯队 | D3、D4、D6 | 各身位晋级与断层、最终炸板、一字与换手差异 | 高度是否有板块支撑、何处竞争激烈、后手能否参与 | 确定重点身位及不宜追随的后排 |
| 五、情绪锚与杀伤 | D2—D4、D6、D8 | 事前角色池 + 竞价至收盘时间线 + 伤害扩散 | 修复关键锚、负反馈源及会被牵连的资金群 | 给出次日必须看的具体锚点和失效信号 |
| 六、题材事件树 | D6、D7，加D2—D4价格响应 | 逐事件映射、传播、新旧催化、前后排响应 | 为何炒、炒到哪、剩余预期由何种后续事件支撑 | 对方向排序，明确延续/升级/兑现条件 |

| 八、赚钱/亏钱效应 | D2—D4、D6、D8 | 按入组日追踪1—3日溢价、样本分布及可参与性 | 什么模式真正赚钱、利润是否留得住、亏损是否扩大 | 选模式和节奏，避免将首板强误当后手接力强 |
| 九、次日应对与候选 | 前八模块 + D4、D7 | 基准/强/弱情景、确认锚、失效链；全首板筛选 | 主攻/回避什么、等什么确认、何时取消预期 | 形成条件式操作计划，次日报告复核执行前提 |

### 2—3日赚钱效应的统一计算

- 不只看D-1样本。按形成日t冻结涨停/核心观察批次，分别追踪t+1、t+2、t+3；到D只计算已经发生的区间，不用未来数据。历史批次保留失败者，不只追踪仍然涨停的股票。
- **先手事件反馈：** 以t收盘为观察基准，计算`(t+k可比收盘价 / t可比收盘价 - 1) × 100%`；k为1、2、3。它只衡量事件形成后的价格反馈，不声称t涨停收盘可买到，也不等于用户实盘收益。
- 每个有效批次保留样本数、正溢价比例、均值、中位数、≤-5%比例及实际跌停数量。均值被少数连板拉高而中位数/多数样本亏损时，明确“赚钱集中，不是普遍好做”。缺失、停牌及特殊价格处理单独记录，不悄悄剔除亏损样本。
- **后手价格参考：** 以t+1有效开盘价为基准，分别计算至t+1、t+2、t+3收盘的同批次收益；这是最接近用户2—3日持股周期的参考轴，但仍不模拟实际成交、费用和滑点。先手事件反馈与后手价格参考必须分列，不能混成一个“溢价”。
- **可参与子集：** 若t+1一字涨停且在用于评价的窗口内没有可确认开板/成交机会，标记为“普通后手不可参与”，保留在全批次先手反馈中，但不进入普通后手收益分母；若缺少分时或开板证据，不得武断判定可参与。完整批次与可参与子集同时保留样本数，防止剔除难买强股后误读。
- **利润留存与峰值回撤：** 对每只可参与样本，从t+1开盘起用已发生的日内高点计算最大有利收益、用日内低点计算最大不利收益，再计算`峰值回撤百分点=区间最大有利收益-区间最终收盘收益`。日线高低价只能说明区间幅度，不能说明先后顺序；需要判断先盈利后回吐时必须有分时顺序证据。
- 对同一有效样本比较t+1与t+2/t+3最终收益，识别第一天有溢价后被吐回，还是盈利可延续；分组口径固定，不能用不同股票两天的均值差冒充同批持仓变化，也不能把理论高点收益写成可兑现收益。
- 模块三保留原有单张五日隔日反馈表；跨2—3日结果集中在模块八以紧凑分组表或证据段解释，不在模块二、三重复加表。仅有一天新题材只能写首日强度，不能预判为已经形成持续赚钱效应。

### FTShare缺失时的问财回退规则

- FTShare按接口、交易日和字段逐项判断是否可用；出现无记录、权限不足、请求超时、返回截断或交易日不匹配时，只对缺失字段调用同花顺问财，不整份报告切换数据源。
- 问财回退查询必须带明确交易日，并在结果中重新执行LINSC股票范围过滤：排除名称含ST或*ST、北交所，纳入主板、创业板和科创板。无法确认过滤条件或统计口径时，该字段写“—”。
- 问财返回的涨停、跌停、上涨/下跌家数、成交额和历史日行情，均须保存查询语句、返回时间、原始结果和过滤后结果；报告正文按字段标注实际来源，不能把问财结果伪装成FTShare结果。
- FTShare已有可靠值的字段不得被问财覆盖；同一指标在同一张表内应保持单一口径。不同日期可以因实际回退情况而拥有不同来源，但必须在内部元数据中记录。
- 问财也查不到或无法形成同一LINSC口径时，保留“—”，不得用相邻日期、5日均值或未过滤的全市场数字倒填。

## 六、数据质量与写作边界

- 数据完整性检查在内部执行，不单独作为报告模块展示。
- 交易日期不一致、核心价格或高标名单冲突时，暂停相关结论并重新取数。
- 近5日指标或历史题材无法取得时保留“—”，不得推测填充。
- 前一交易日成交额或60个完整交易日成交额不足时，相应比较值写“—”并降低量能判断置信度；不得用近5日均值、当前网页显示值或相邻日期倒填60日均值。
- 高位核心杀伤、早盘跌停和昨日涨停反馈属于超短情绪的硬指标，必须先计算后写作；缺少这些数据时，不能用指数和涨停家数替代。
- 内部情绪痛感否决统一执行第三节的`A 或 (B 且 C)`及关键锚单独否决规则，不另写具有不同括号含义的条件。缺少A所需时间数据时不能当A为假；只依据已确认信号给出下限，并限制进一步周期确认。达到高或极高痛感时，不得输出“主升延续”或普通“弱修复”。
- 报告首段必须分别给出大盘环境、超短接力、情绪痛感和接力可做性，避免用单一“市场情绪”标签掩盖结构性背离。
- 韭研公社内容采用三层保存：**原始内容层**保存页面、标题、正文、发布时间和页面地址；**个股事件卡层**拆出具体事件、触发时间、个股映射、市场叙事和价格反应；**题材聚合层**总结主线、扩散、预期和持续性。二次归纳只能作为上层索引，不能替代原始内容或事件卡。
- 一只股票可以对应多个事件；不同事件不得因同属一个题材而合并。同一事件被多篇帖子重复传播时，只合并事件主体，保留首次出现、后续传播和不同个股映射记录。
- 事件卡至少记录：股票代码和名称、事件类型、事件标题或关键词、事件细节、传播时间、来源类别、个股映射、市场正在交易的预期、当日价格反应、原始内容哈希和来源地址。完整原文留在本地缓存，报告只做精确归纳和必要的短语引用。
- 采集与报告生成分离：先按交易日增量采集并去重，再由报告生成器读取事件卡；生成报告时不得临时依赖无缓存的整站搜索结果。
- 韭研公社采集顺序以涨停票为优先：先读取同日客观涨停池形成 `priorityStocks`，再采集涨停核心、1进2候选和高标相关叙事，最后补充题材文章、热榜和其他帖子；首页不作为个股异动的替代数据。
- 盘中监控不是必需条件：若盘中未启动或中途停止，报告生成前必须执行一次同日补抓，先完成行情取数和涨停优先清单，再进入报告生成；补抓失败只能降低叙事覆盖，不得伪造内容。
- 盘中持续监控由用户在本机手动启动：FTShare每60秒检查涨停池，新涨停只入队一次；第一批韭研公社采集立即执行，后续按30分钟冷却批量处理，每日最多8批。浏览器登录状态仅保存在本机，不保存账号密码，不上传GitHub或服务器。
- 缓存采用追加更新而非覆盖删除，保留同一页面的更新时间和版本；内部可以记录“未找到个股异动解析”，但正文不展示该提示，改用有效的板块文章或其他帖子补写。
- 小作文、帖子和预期差描述的是市场叙事强度，不等于事实确认；正文不做公告核验，但措辞应使用“市场交易”“市场讨论”“预期”等表述。
- 不设“高标卡异动、绕异动”独立模块。
- 次日操作指导集中在模块九，以具体证据和情景条件呈现，不另设空泛、重复的通用操作模块。最新需求优先于此前“不写次日操作”的旧约定。
- 报告使用Markdown规则生成静态内容；由用户在对话或网页端手动发起，同一日期允许重新生成并覆盖原报告，不安排每日自动生成。重新生成保留输入与旧版追溯信息；默认交付MD、紧凑PDF及既定服务器上传核验，不自动更新GitHub代码或发布网站。

## 七、生成顺序与完成标准

以下为后续生成器应落实的规则，本次仅写入底稿。九个模块是展示顺序，不是计算顺序。

| 步骤 | 必须取数/处理 | 可检查的产物与通过条件 |
| --- | --- | --- |
| 1. 锁定任务 | D、交易日历、正文消息截止时点、底稿版本；读取前日报告的判断与条件 | 明确历史回放边界、近5日及下一交易日，不能引入D之后的信息 |
| 2. 取得客观输入 | D及比较日行情、当日/昨日涨跌停与触板记录、前60日成交额、核心池历史 | 分页/总数/截断状态、逐条交易日、单位和股票范围均有记录；五日各行的前5日核心池需要额外历史回溯，不能只取五天数据 |
| 3. 缺项定向补取 | 缺字段先问财，再按矩阵回退；历史已有合格原始缓存可重算，用户要求全部重取时执行新请求并留版本 | 保存具体查询、返回时间、原始结果、过滤结果；有限重试后列出未解决字段，不无期限循环。未实际尝试不得写“后备源也不可用” |
| 4. 计算统计 | 统一范围的成交额/五日表、昨日反馈/分组、梯队、核心池及杀伤时间线 | 输出独立客观结果；每项有样本代码、分母、数据路径和计算口径，模型不可改写 |
| 5. 补抓市场叙事 | 优先涨停股、候选、高标、旧核心，再补板块文章 | 原始正文 → 个股事件卡 → 题材聚合；成功页面数不等于事件覆盖率。遇限流、验证码停止该来源并按合规后备/已有有效缓存降级，不绕过访问限制 |
| 6. 写分项分析 | 先模块三至八，再模块九；逐项引用客观结果与事件卡 | 每个判断有对应指标/个股/事件，必要的缺失保留；不是先写结论再选择有利证据 |
| 7. 回填总判断 | 双轴、痛感否决、前日预期验证，再写模块二及模块一 | 周期类别合法、表述与负反馈不冲突、前日结论可被修正，核心大面不等于昨日样本大面 |
| 8. 内容验收 | 核对以下九模块清单及跨模块一致性 | 区分标题齐全、统计正确、叙事充分三项；只有标题校验通过不能宣称严格落实底稿 |
| 9. 制作与交付 | 保存MD及结构化数据、生成紧凑PDF、检查页面、上传MD/PDF | 文件交易日一致、表格可读不裁切、全部页面检查；远端文件名、大小及哈希一致后才称上传完成 |

### 九模块逐项验收

- **一：** 五项结论齐全，先说活跃短线资金处境，不堆砌数字、不用指数冲淡核心杀伤。
- **二：** 同范围成交额两组比较；仅一张倒序5日总览；双轴、痛感、周期、前日验证及迁移条件齐全。60日不足允许“—”，不得据此断言相对60日放量或缩量。
- **三：** 仅一张倒序5日反馈表；样本分母统一；红开、收红、晋级、大面、真实跌停均可追溯；10/20cm及高低位显著差异有解释。
- **四：** 10/20cm分开；连续板与多日多板分开；断层、竞争、可参与性与最终炸板口径清楚。
- **五：** 正负锚均有依据；早盘触跌停后打开的核心不漏；角色、时点、收盘及影响串成链条，完整杀伤清单只出现一次。
- **六：** 核心题材具体事件、个股映射、消息层次、扩散证据及预期空间齐全；不能以标签或泛化故事替代事件。
- **七：** 重点题材逐日阶段和领涨核心表现可回放，包含失效题材与换锚；不拿今天的龙头代写过去。
- **八：** 七类风格逐项说明样本或缺样本、1—3日溢价及其分布、可参与性、体感与难度；单个幸存者不代表整体赚钱。
- **九：** 有具体主攻/回避方向、观察锚及强/基准/弱情景的操作应对；全首板筛选有记录，入选者有行情、实际叙事、两段炒作逻辑及条件预判。允许无候选，不拿概念标签凑数；无候选也须说明整体应对。

### 结论边界与内部留痕

- 每项指标记录来源、日期、范围、分母、缓存路径；每个关键分析对应数据或事件卡。旧报告只是对比材料，不是来源不明数值的备份。
- 缺失分三层处理：非关键字段保留“—”并限制对应解释；个股叙事不足则不写对应消息/不纳入候选；核心行情冲突、交易日错位或关键统计无法确认则暂停相关正式周期结论，不用确定语气完成模板。
- 历史数值或口径修正时，在表下简短注明修正项，避免前后报告无解释地改变；正文仍不新增“数据完整性”模块，也不展示凭据和采集内部日志。
- 内容可以紧凑，但不能以页数、消息条数或搜索轮次上限删去必要的事件和反证。交付摘要分别说明已完成的文件、上传结果与仍存在的实质限制，不能用“全部完成”掩盖未取到的数据。

## 八、交给其他模型的执行约定

### 最小输入包

1. 本文件全文、目标交易日D、消息截止时点和用户已确认的操作模式。本文件不够时显式指出缺项，不能依靠本对话猜测。
2. D1—D8原始数据/缓存及来源索引；至少提供各指标的日期、单位、范围、有效分母和缺失原因。仅给旧日报正文不等于已经提供原始数据。
3. 可复算的统计结果、当时核心池、事件卡及前几日报告。可采用JSON保存输入和结果，原始网页正文单独缓存；不依赖特定数据库或特定模型API。
4. 数据工具的实际调用说明或已取得的数据文件。新模型若没有FTShare、问财或韭研访问能力，必须由外部采集层提供数据；仅有本底稿不能使模型凭空获得实时/历史行情。

### 单项结果记录

- **统计项：** 指标名、交易日/窗口、值、单位、股票范围、原始/有效样本数、公式或方法、来源路径、缺失状态。
- **判断项：** 模块、结论、支持证据ID、相反证据、未知项、为何得出该结论、次日确认/失效条件。
- **情景项：** 基准/强/弱情景、具体观察锚、可见触发信号、对应操作应对、切换条件；不编概率。
